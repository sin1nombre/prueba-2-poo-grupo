# prueba-2-poo-grupo

Repositorio para la evaluación 2 de Programación Orientada a Objetos.

---

### Clona el repositorio

Abre tu terminal en la carpeta donde quieras guardar el proyecto y ejecuta:

```bash
git clone [https://github.com/sin1nombre/prueba-2-poo-grupo.git](https://github.com/sin1nombre/prueba-2-poo-grupo.git)
cd prueba-2-poo-grupo
```

Verifica o configura tu usuario local:

```bash
git config user.name "Tu Nombre"
git config user.email "tu_correo@ejemplo.com"
```
